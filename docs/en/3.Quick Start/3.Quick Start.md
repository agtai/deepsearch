DeepSearch is a knowledge-augmented, high-performance deep retrieval and research engine. It uses structured knowledge and LLMs with tools to deliver enterprise Agentic AI search and research. This document walks through using DeepSearch for report-oriented research.

## 1. Preparation

> **Note**: The product has separate front-end and back-end projects. Before you start, ensure both are deployed and running. If not, follow the [DeepSearch Full Edition installation guide](../2.Installation%20Guide/DeepSearch%20Full%20Edition/README.md).

### 1. Get an LLM API key

DeepSearch needs an LLM. Purchase or host a model from a provider. The steps below use Huawei Cloud as an example.

* Open the [ModelArts deployment console](https://console.huaweicloud.com/modelarts/?locale=zh-cn&region=cn-southwest-2#/model-studio/deployment) (online inference).

* Pick a model and click **Enable service**.

  ![images](../images/快速上手/华为云-模型广场.png)

* After enabling, open **Invocation guide** for model details.

  ![images](../images/快速上手/华为云-模型配置.png)

* Open **OpenAI-compatible API** and note the *API endpoint* and *model* parameter.

* Under **API key management**, create a key per the console.

> Details: [Huawei Cloud ModelArts MaaS user guide](https://support.huaweicloud.com/usermanual-maas-modelarts/maas-modelarts-0195.html)

---
### 2. Get a web search / augmentation API key

DeepSearch uses a web augmentation service (e.g. [Tavily](https://www.tavily.com/)) to fetch online information.

![images](../images/快速上手/Tavily-api-key.png)

> Tavily: [official documentation](https://docs.tavily.com/documentation/about)

---
### 3. Model configuration

In **Model management**, click **Add model**. Fill in **Model name**, **Model ID**, **API key**, **Base URL**, and **Description**.

* **Model name**: Display name; you choose.
* **Model ID**: Provider’s model id (matches Huawei *model* parameter).
* **API key**: From the provider (Huawei *API Key*).
* **Base URL**: Provider API base URL (Huawei *API address*).
* **Description**: Optional notes.

  ![images](../images/快速上手/快速上手-模型配置.png)

Test the model:

* In model management, click **Test** on a model.
* Pick a sample prompt.
* Click start; **Test succeeded** means configuration is OK.

  ![images](../images/快速上手/快速上手-模型测试.png)

> If testing fails, double-check endpoint, model id, and key.

### 1. Prerequisites

Open **Task space** to reach the agent chat UI.

![images](../images/快速上手/快速上手-任务空间.png)

Before using DeepSearch, complete the following.

In the input box type `@DeepSearch` to pick the agent.

![Select agent](../images/快速上手/选择智能体.png)

The first time (or if setup is incomplete), a configuration dialog appears—use [Agent configuration](#agent-configuration) below, then **Save configuration**.

> After saving, the DeepSearch agent is active.

<a id="agent-configuration"></a>

---
#### Agent configuration

Click **Configure** next to the DeepSearch agent.

![Agent config entry](../images/快速上手/智能体配置入口.png)

Three tabs group the settings.

> Click **Save configuration** when done.

#### General

* **Human-in-the-loop**: When on, the agent may ask for confirmation at key steps.
* **Enable provenance**: When on, results show sources.
* **Number of sections**: Max report sections (1–10); higher values mean more detailed planning.

#### Search

![Agent config entry](../images/快速上手/智能体联网增强引擎配置.png)

* **Search mode**
  - [x] **Web augmentation**: Use a web augmentation engine.
  - [ ] **Local search (not available yet)**: Knowledge base only.
  - [ ] **Hybrid (not available yet)**: Local + web.

* **Search sources**
  - [x] **Web augmentation engine**: Configure engines (iFlytek, Petal AI, Tavily, Google, custom).
  - [ ] **Local knowledge base (not available yet)**: Select one or more KBs.

#### Templates (optional)

To control report structure, use templates.

* **Available templates**: Pick from the list.
* **Import template**: **Upload new template** from a sample.
  * **Extract**: Auto-extract structure from Markdown, HTML, Word, or PDF.
    </br>![Template extract](../images/快速上手/模板提取生成.png)
  * **Use as template**: Use a Markdown file directly as the template.
    </br>![Pick template](../images/快速上手/选择模板.png)

> Templates are optional.

#### Model assignment

Assign models per research stage for quality vs cost.

![Model config](../images/快速上手/模型配置.png)

**Basic**

- **General model** (required): Default for all stages when advanced slots are empty. Prefer a strong general model.

**Advanced** (optional)

Per-stage overrides; unset stages use the general model.

- **Outline generation**: Prefer a strong reasoning model.
- **Information gathering**: Lightweight model is often enough.
- **Report writing**: Prefer models strong at code/math for accuracy.

> Advanced is optional. All stages need **function calling** support.

---
#### Choose the chat model

Use the model picker in the top-right of the chat.

![Pick model](../images/快速上手/选择模型.png)

> You must select a model. Context under 128K may limit long research reports.

### 2. Conversation flow

#### 2.1 Ask a question

![images](../images/快速上手/对话框-输入框.png)

> **Notes**  
> - Type in area **1**, send with **2**.  
> - Two modes: HITL (human-in-the-loop) and non-HITL.

##### 2.1.1 HITL mode

Two user turns:

1. You ask; DeepSearch may ask follow-ups.
   - Yellow indicator (**1**) = waiting for your reply.
   - Type feedback in **2** and send.  
   </br>![images](../images/快速上手/对话框-HITL模式系统回复1.png)
2. After your reply, the run continues.
   - Green (**3**) = feedback received.
   - **4** shows your message; **5** shows report generation starting.  
   </br>![images](../images/快速上手/对话框-HITL模式系统回复2.png)

##### 2.1.2 Non-HITL mode

One turn: you ask → DeepSearch generates the report directly.

> Report generation behaves the same afterward; below uses non-HITL for the UI tour.

---
#### 2.2 Message panel

##### 2.2.1 Regions

![images](../images/快速上手/对话框-进行中的用户及消息框.png)

1. **1**: Your message.
2. **2**: Assistant message.
3. **3**: Step status: hollow gray = not started; spinner = running; green check = done; red = failed; yellow = stopped manually.

5. **5**: Section duration `d*h*m*s` (updates while running, fixed when done).
6. **6**: Expand/collapse body.
7. **7**: Sub-sections.
8. **8**: Expand/collapse sub-sections.
